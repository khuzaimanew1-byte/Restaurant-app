Before changing card visuals, completely redesign the card state system.

The current implementation mixes arrival status, departure status, leave status, and attendance metrics inside the same visual layer, creating overlapping conditions and weak hierarchy.

Create a proper status-priority architecture first.

==================================================
TIME & LEAVE PAGE
=================

Rename page:

Leave
→
Time & Leave

At the top of the page display only:

Office Timing
08:00 AM – 06:00 PM

This section must be editable.

No widgets, stats, counters, charts, summaries, or additional sections above it.

Office Timing acts as the global attendance rule.

==================================================
CARD STATUS SYSTEM
==================

A card can contain:

* Arrival Status
* Departure Status
* Leave Status

These are separate systems.

Do not mix them.

Only the highest-priority state may be visually displayed.

==================================================
ARRIVAL STATUS RULES
====================

Arrival status is evaluated only when Check-in exists.

If Check-in is empty:

No arrival status exists.

Arrival states:

1. Arrival
2. Late Arrival

Arrival combines:

* Early Arrival
* On-Time Arrival

Do not create separate Early Arrival or On-Time Arrival states.

Arrival:

Dot Color:
Green (#22C55E)

Check-in Time Color:
Green (#22C55E)

Late Arrival:

Dot Color:
Amber (#F59E0B)

Check-in Time Color:
Amber (#F59E0B)

Check-in time color must always match arrival status color.

==================================================
DEPARTURE STATUS RULES
======================

Departure status must never be evaluated until Checkout exists.

If Checkout is empty:

No departure status exists.

Departure states:

1. Early Departure
2. Normal Departure

Early Departure:

Dot Color:
Purple (#A78BFA)

Check-out Time Color:
Purple (#A78BFA)

Normal Departure:

No status color.

Check-out time uses default text color.

==================================================
LEAVE STATES

Leave states override attendance states.

Label Color:
Teal (#14B8A6)

Check-in Time Color:
Teal (#14B8A6)

Check-out Time Color:
Teal (#14B8A6)

Remove all Half Day badges.

Half Day must rely only on its status color and label.

==================================================

============================

Status color must always be applied consistently.

Whenever a status is active:

* Status Dot
* Status Label
* Check-in Time
* Check-out Time

must visually follow the active status color whenever those elements exist.

Examples:

Early Departure

Leave

Gray Label

Coral Red Dot

Half Day

Teal Dot
Teal Label
Teal Check-in Time
Teal Check-out Time

Never mix status colors with default colors when a status color exists.

==================================================
HALF DAY RULES
==============

Half Day is a controlled attendance state.

Half Day option remains disabled unless:

* Check-in exists
* Check-out exists
* Employee qualifies as Early Departure

All three conditions must be true.

Only then may Half Day be assigned.

If employee does not qualify for Early Departure:

Half Day option must remain disabled.

Half Day may contain:

* Check-in
* Check-out

Half Day is the only leave-related state allowed to coexist with attendance times.

==================================================
DATA VALIDATION
===============

Check-out cannot exist before Check-in.

User must enter Check-in first.

Only after Check-in exists:

Check-out becomes editable.

Only after Check-out exists:

Departure rules may be evaluated.

Prevent all invalid attendance sequences.
