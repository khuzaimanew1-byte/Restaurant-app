## Philosophy

Login ek chore nahi hona chahiye. User ko pata bhi nahi chalna chahiye ke woh security steps se guzar raha hai. Har cheez naturally flow kare, koi friction nahi, koi confusion nahi.

## Layout & Structure

Single centered card, vertically middle of screen. Card nahi — floating content, no borders, no shadows, just space. Content itna kam ho ke user ko scan karna na pare — seedha action kare.

Top pe app name, chhota. Phir heading, bold. Phir inputs. Phir button. Forgot password bilkul neeche, small — present hai lekin attention nahi maangta.

elements breathe karein. Cramped nahi lage.

## Typography

Heading large, bold, warm white — anchors the screen.
Subtext chhota, muted — supporting role, lead nahi.
Button text medium, dark on amber — confident, readable.
Error text chhota, red — visible but not screaming.

## Inputs

Bottom stroke only. Jab focus ho toh border cover animation aaye, smoothly. No box, no background, no radius. Label placeholder ke taur pe — jab type karo toh upar float kare gently. Eye icon password ke right pe, always visible.

## Animations

**Form load** — elements upar se fade in, staggered, 40ms apart. Subtle, barely noticeable — lekin absence mein stiff lagta.

**Input focus** — stroke brightens, 180ms ease. No jump.

**Button press** — scale 0.97, 120ms. Spring back.

**Wrong OTP** — horizontal shake, 300ms. Boxes border red. No text — shake kaafi hai.

**Wrong password** — input border flash red, 200ms. Error text fade in neeche.

**OTP auto-advance** — cursor next box pe instantly. Paste — sab boxes bhar jayein, submit.

**Screen transition** — current content fade out, new fade in. 200ms. No slide — slide distracting hota hai, fade cleaner.

**Success** — button spinner → checkmark → fade out page → dashboard.

## Psychological Positioning

**Anchoring** — App name upar chhota, heading bold — user ko context milta hai without reading.

**Progressive disclosure** — sirf jo zaroorat hai woh dikhao. OTP screen pe sirf boxes — koi extra text, koi instruction paragraph nahi.

**Fitts Law** — button full width — impossible to miss, thumb-friendly on mobile.

**Hick's Law** — choices zero. Ek input, ek action. User ka brain decision fatigue mein nahi jaata.

**Error recovery** — error seedha us cheez ke neeche jahan galti hui. User ki eye wahan pehle se hai — no hunting.

**Trust** — clean space, consistent amber, no clutter — subconsciously professional aur trustworthy lagta hai.

**Resend link muted** — jab tak ready nahi — user try nahi karta baar baar, cooldown naturally feel hota hai without hard block message.

**Forgot password neeche** — present for those who need it. No anxiety trigger for normal users.
